# 💻 Plataforma de Servicios Tecnológicos

Sistema web en *PHP + MySQL + Bootstrap* para gestionar *servicios, **tickets de soporte, **asignación de técnicos* y *comentarios*. Ideal para equipos de TI o soporte que necesiten administrar incidencias.

---

## 🚀 Características
- 🔐 *Login* con roles: admin, tecnico, cliente
- 🧩 *Servicios*: crear, editar, eliminar (admin)
- 🧾 *Tickets*: creación por clientes/admin, estados (abierto, en_progreso, resuelto, cerrado)
- 👨‍🔧 *Asignación de técnicos* por ticket (admin/técnico)
- 💬 *Comentarios* dentro del ticket
- 🧱 Estructura lista para *XAMPP* (local)
